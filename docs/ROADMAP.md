# Roadmap

At the start of each session, agents report the current milestone, its status and what comes next.

## Product
This is a daily game platform, named **Plor** (human, 2026-10-18; at `plor.app`). It should feel welcoming but neutral (human, 2026-10-19). Players play the day's game, watch friends' runs live (including where each friend "died"), comment and react on the day's game, and earn cumulative points for a friends leaderboard. It's built to hold more than one game later, but it ships with one.

**Game 1: Don't Match the Host.** Each day has 7 fixed, independent questions that mix concrete and abstract (e.g. "Name a day of the month", "Name something you'd bring to a potluck"). The player names an answer and must avoid the host's secret answers, which catch a slowly rising share of players through the day. Niche answers are a fair escape, and some days are harder than others. Matching ends the run, and the score is the number of questions survived. See DECISIONS.md for the answer model.

Tickets for M02 and later get written when their milestone comes up, so they don't go stale.
After the MVP (human, 2026-10-19): **game 2**, a daily word-guessing game under its own name, look and word list. Not Wordle's name or its green, yellow and gray tiles: in 2024 the New York Times sent takedown notices over exactly those, while saying it has no issue with similar games that don't infringe its trademarks or copyrighted gameplay (Fortune, 2024-03-13). Not legal advice; ask a lawyer before money is involved. **Game 3**, a word chain ("off → w___ → white → white h___ → white house"). **Game 4**, anagrams: find as many words as possible in the day's letters. **Game 5**, a word hunt: find words in a letter grid. Games 4 and 5 both have a **bonus letter**: each word that uses it earns extra points (human, 2026-10-19; the point values are human numbers for their tickets). Games 2, 4 and 5 need one shared **dictionary**: a word list whose license allows use in Plor (pinned in SOURCES.md and approved by the human), with offensive words and proper nouns removed, and the server as the only judge of a valid word, so the full answer list never reaches the client. The word chain needs a separate list of two-word phrases. **Leaderboards across games:** each game has its own leaderboard, plus an overall one that adds up all games (human, 2026-10-19). Because the total adds points from different games, each game's point values (human numbers) also decide how much it weighs in the total. Pull the platform/game boundary out at game 2. Then order the rest by beta data: streaks, answer stats ("12% picked lion"), reminders, an admin UI for content, a global leaderboard (out of scope for now, human 2026-10-19), a native app wrapper, public comment moderation.
